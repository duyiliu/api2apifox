## 5. 补测试发现的真实缺陷与风险（未改产品代码，仅锁定 + 报告）

| D3 | P2 风险 | client 收到 200 + 非 JSON（如代理返回 HTML）时**静默返回空列表**不报错；业务码为字符串 `"0"` 时绕过错误检查（只认 number） | `clientMatrix.test.ts` 对应用例（标注"已知静默点"） |

### 9.1 130 的造法（Windows 限制说明）

Node 在 Windows 上对子进程发 OS 级 SIGINT 是**直接终止**（本机实测 `close(code=null, signal=SIGINT)`，JS 收不到事件），因此 130 不能用子进程信号复现（与之前 C13 同类平台限制）。改为在进程内用 `process.emit("SIGINT")` 驱动导出给测试的 `runCli`，完整走 `SIGINT → AbortController → client AbortError → CANCELLED → 130` 的真实代码路径；POSIX 上 OS 信号也进同一路径。平台注记用例锁定 Windows 差异，非 Windows 自动跳过。

### 9.2 新增观察（未改产品代码）
